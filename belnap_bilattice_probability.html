Belnap's bilattice: truth values as weight carriers that normalise to probabilities

Belnap's FOUR as a unit square

Each truth value is a point ⟨t, f⟩ ∈ {0,1}². The two orderings are independent axes.

From weights to probability

Treat t and f as raw support weights. When t + f > 0, normalise: P = t / (t + f). This is just Laplace's rule of succession stripped bare — the fraction of positive evidence among all evidence received. When both are zero (N), the probability is undefined (no evidence).

Adjust weights

Move beyond the four corner values into the continuous generalisation: t, f ∈ [0, 1].
