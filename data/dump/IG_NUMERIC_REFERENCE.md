# Imscribing Grammar — Numeric Quick Reference

Numbers replace the Shavian glyph for each value. ⊙ (Criticality, value 2 of its own
axis) is kept literal — it is the fixed point, not a numbered value.

Canonical tuple order: ⊢ ⊣ ≻ ≺ ⋈ ⊤ ∈ ∋ ⊙ ⊥ ⊞ ⊡

---

## ⊢ — Dimensionality (4 values)

| # | Meaning |
|---|---------|
| 1 | flat local sheet — no recursive nesting |
| 2 | simplicial / stratified — finite depth |
| 3 | infinite-dimensional — unbounded temporal/spatial generation |
| 4 | imscriptive — the encoding writes what it encodes. Holographic (a boundary that encodes a bulk it doesn't write) is a static special case of this, not a synonym for it. |

## ⊣ — Topology (5 values)

| # | Meaning |
|---|---------|
| 1 | general graph — heterogeneous, locally connected |
| 2 | inclusion / nested — hierarchical containment |
| 3 | bowtie / figure-8 — two-cycle closure, a bifurcation point |
| 4 | box / lattice — regular grid or torus |
| 5 | holographic — the boundary fully encodes the bulk |

## ≻ — Relational Mode (4 values)

| # | Meaning |
|---|---------|
| 1 | supervisory / hierarchical — one-way authority |
| 2 | categorical / compositional — functorial chaining |
| 3 | dagger / reciprocal — A and A† co-define each other |
| 4 | lateral / peer — symmetric two-way exchange |

## ≺ — Parity / Symmetry (5 values)

| # | Meaning |
|---|---------|
| 1 | asymmetric — no symmetry axis |
| 2 | phase symmetry — U(1) or continuous phase |
| 3 | ℤ₂ discrete symmetry — sign flip |
| 4 | full continuous symmetry — e.g. SO(n) |
| 5 | Special Frobenius — μ∘δ=id; exact ℤ₂ at ⊙. Cannot be reached by composing two values below it (§23) — the weaker partner always wins under tensor. |

## ⋈ — Fidelity (3 values)

*Bottleneck primitive under ⊗ — the weaker partner wins (min), not the stronger.*

| # | Meaning |
|---|---------|
| 1 | classical, lossy |
| 2 | threshold / HotSwap |
| 3 | quantum, high-fidelity |

## ⊤ — Kinetic Character (5 values)

| # | Meaning |
|---|---------|
| 1 | diffusion-limited, untrapped |
| 2 | moderate threshold |
| 3 | slow / thermally activated — passes Gate 2 of the consciousness score |
| 4 | kinetically trapped by order (e.g. over-consolidated bureaucracy, catatonia) |
| 5 | many-body localized — frozen by disorder (e.g. dissociation, societal collapse) |

Values 4 and 5 both fail Gate 2 of the consciousness score, for opposite reasons, and need
opposite interventions to restore: value 4 needs disorder injected in; value 5 needs
ergodicity restored.

## ∈ — Scope / Granularity (3 values)

| # | Meaning |
|---|---------|
| 1 | local / mesoscale — short-range correlations |
| 2 | intermediate / collective |
| 3 | global / fine-grained — all-to-all correlations |

## ∋ — Interaction Grammar (4 values)

| # | Meaning |
|---|---------|
| 1 | conjunctive — all conditions required simultaneously |
| 2 | disjunctive — any condition sufficient |
| 3 | sequential — strict temporal or causal ordering |
| 4 | broadcast — one-to-all coupling |

## ⊙ — Criticality (5 values)

| # | Meaning |
|---|---------|
| 1 | subcritical — stable, ordered phase |
| **⊙** | real-axis Hermitian criticality — the standard fixed point. Absorbing under meet: meet(⊙, x) = ⊙ for any x, by a custom lattice rule, not the plain min. |
| 3 | complex-axis criticality — analytic continuation required (Lee-Yang edge, complex RG fixed point, ζ-function zeros) |
| 4 | exceptional-point criticality — non-Hermitian eigenvector coalescence, a square-root branch point |
| 5 | supercritical — unstable, runaway |

## ⊥ — Chirality (4 values)

| # | Meaning |
|---|---------|
| 1 | achiral — shift-invariant, no handedness to break |
| 2 | soft chiral — period-2 under the shift |
| 3 | persistent chiral — a descent through rank |
| 4 | topological chiral — inexhaustible, no finite return |

## ⊞ — Stoichiometry (3 values)

| # | Meaning |
|---|---------|
| 1 | 1:1 |
| 2 | n:n — matched many-to-many |
| 3 | n:m — unmatched many-to-many |

## ⊡ — Topological Protection (4 values)

| # | Meaning |
|---|---------|
| 1 | no topological protection |
| 2 | ℤ₂ symmetry protection |
| 3 | integer winding number — ℤ protection |
| 4 | non-Abelian / non-standard protection — occupies this slot as the most exotic tier, not necessarily the strongest in a linear sense |

## Cross-Primitive Axioms

- **Axiom B:** ⊡=3 (ℤ protection) requires ⊥≥3 (persistent chiral); ⊡=2 (ℤ₂ protection)
  requires ⊥≥2 (soft chiral). You need enough chirality to have a direction before you
  can wind in it.
- **Axiom C (revised):** ⊣=5 (holographic topology) forces ⊢=4 (imscriptive
  dimensionality) — the converse does not hold. ⊢=4 permits ⊣=4 (box/lattice) instead;
  the Stone and its catalog co-types carry ⊢=4+⊣=4, never ⊢=4+⊣=5. Confirmed against 9
  independently encoded O∞ systems.
- **Axiom D (Holographic Closure):** ⊢=4 and ⊣=5 and ⊡≥3 together force ≺=5 (Special
  Frobenius). A boundary-encoding that is complete (⊣=5), exact (⊢=4), and
  topologically protected (⊡≥3) has a right inverse — that is what ≺=5 means. Any
  other parity value under those three conditions is structurally inconsistent.
- **Tendency, not an axiom:** ⊥=4 (topological chirality) tends to co-occur with ⊤=4
  (kinetically trapped by order) — an inexhaustible tower stands because its store is
  frozen. Not a hard rule: some ⊥=4 systems (e.g. proto-languages) carry ⊤=3 instead.

## O-Tier Hierarchy

Determined by exactly four primitives: ⊙ (Criticality), ≺ (Parity), ⊡ (Protection), ⊢
(Dimensionality) — plus ⊣ (Topology) for one lateral rule.

- **R1** (dominant, checked first): ⊙∈{critical,complex-crit} and ≺=5 (Special
  Frobenius) → **O∞**. This overrides every other rule.
- **R2:** ⊙∉{critical,complex-crit} → **O₀**.
- **R6** (checked only after R1 fails): ⊢=1 (flat local) and ⊣=3 (bowtie) and ⊡=3
  (integer winding) → **O∞-dagger**. Lateral to O∞, not above or below it — a
  self-replicative opening rather than a terminal closure. Never returned when ≺=5 (R1
  always wins when both apply).
- **R3:** ⊡=1 (no protection) → **O₁**.
- **R4:** ⊢≠3 (not infinite-dimensional) → **O₂**.
- **R5:** ⊢=3 (infinite-dimensional) → **O₂-dagger**.

No tier sits above O∞; O∞-dagger is beside it, not below it — a linear tier list has no
way to write "beside," so this reads as a demotion if you're not holding the lateral
case separately.
