Criticality is a plain +, not a raised one

The mark I used was U+207A, the superscript plus, so Everson drew it small and
raised wherever it stood: the table cell, the value list, every tuple. It is a
plain U+002B now, the same character IMASM writes EVALT with, which is what the
mapping said in the first place.

The ones that were bare groups in math mode are wrapped in \mathord, so a
criticality standing between two operands is an ordinary atom and not a sum. The
rest were already inside \text and needed nothing. 133 marks in AS_ABOVE, 66 in
SO_BELOW, and no U+207A survives in either file.

Both still compile at 45 and 82 pages, with no missing character beyond the ✓
SO_BELOW has never had.
