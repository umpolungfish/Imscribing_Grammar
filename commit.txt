The provider's thinking default belongs to ob3ect, not the agent

I flipped this module global to ON when I unified IG_THINK, and it is the global
that governs ob3ect's design call — whose own --thinking flag is documented as
default off and which sets this to True only when the flag is given. So every
design call started thinking, the local kernel spent its output inside the think
block, `ask --raw` returned the empty text after `</think>`, the JSON parse
raised, and with --retries at its default of infinity the pipeline re-asked
forever: a wall of "streaming from LocalProvider / stream complete" with nothing
in between.

Off unless asked, as documented, with an explicit IG_THINK=1 still turning it on.
The agent loop never read this global — it has its own reader and stays on by
default there, where a THINK phase is the point.
