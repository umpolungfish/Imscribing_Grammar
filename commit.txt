The reference docs carry the new alphabet

IG.md, README.md, the reference sheet and the 1-page tex are on the twelve marks.
The compendium is regenerated through scripts/gen_ig_reference.py rather than
hand-edited.

Two things the regeneration exposed. The generator set the primitive column in
FreeSerif, which carries almost none of the new marks, and unicode-math only
rescues the ones that are math operators — ◻ is a geometric shape, so Winding
printed as a missing-glyph box. The twelve now route through Everson Mono, the
same way the Shavian block already did. And the Crystal of Types footer listed
the axes by hand, so it was still naming the retired alphabet after the table
above it had moved; it reads off PRIMITIVES now.

IG_REFERENCE.tex at the repo root does not compile and did not compile on the
frozen branch either — an undefined control sequence at a \text in math mode,
unrelated to the alphabet.
