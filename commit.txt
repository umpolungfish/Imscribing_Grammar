bughunter: read IG_PROVIDER/IG_MODEL like every other operator

The launcher's --model help said "Taken from $IG_PROVIDER and $IG_MODEL", and
it was not. --model defaulted to None and nothing read the environment, so a
flagless run fell through to the base constructor's hardcoded default and ignored
the shell's provider entirely — the env every other operator honours and the
whole constellation is configured through.

Resolution copied from the working operators: absent --model, read IG_MODEL and
IG_PROVIDER, compose provider:model, and exit with the same clear instruction
when IG_MODEL is unset. os was not even imported; it is now.

check_tools_deep.py now asserts every launcher's source reads IG_MODEL, so a
launcher that silently ignores the environment fails the check rather than a run.
