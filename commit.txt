Streaming: IG_STREAM (or --stream) shows local generation token by token as it is
produced. TextIteratorStreamer on a worker thread, drained to stderr so stdout
stays the agent's output; the tensor result is still what gets decoded, so the
parsing path is untouched. Off by default — the loop's log is the normal view and
raw tokens interleaved with it are noise. The flag is on the base agent and on all
nine specialists, and it sets the same IG_STREAM the reader consults, so the flag
and the variable are one switch rather than two.

Identity: the operator was narrating its own tool call as somebody else's — "the
user has already used imasm to derive a tuple", about a call it made itself. Tool
results correctly use the tool role, and the template renders them inside a user
turn, which is the Qwen convention; what was missing was any statement of WHOSE
call produced them. The UPDATE line now says so: YOU called <tool>, and the
<tool_response> above is what YOUR call returned.
