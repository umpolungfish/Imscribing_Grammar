A walkthrough for the MoDoT verbs, with imasm as a language.

Each chemistry verb is given by the question it answers, in both vocabularies, since the flag list alone does not let an agent choose. The second engine was written up as a graph checker, which undersells it badly: it is an alphabet you write programs in, type-check, carry to the kernel as a proof obligation, define new tools inside, unfold types through, and walk promotion paths along, with a wordbook that turns any catalog entry into a program.
