Write axiom4's temporal test as one member, with the history that explains it

The test read `dimensionality in (array, array)` — the same member twice, which
looks like a copy-paste slip and would neatly explain why a sixth of the catalog
fails this axiom. It is not a slip. git log -L shows the line was
(D_invomega, TEMPORAL), and the commit that gave the enums Shavian names had
D_invomega = 𐑼 and TEMPORAL = 𐑼: two names for one glyph. Collapsing both onto
array is behaviourally identical and the test does what the docstring says.

Rewritten as a single `is` comparison with that history in a comment so it stops
inviting a fix it does not need. Violation counts unchanged, which is the point.

What that leaves standing is the real finding, recorded in the audit doc: 1332 of
2880 sequential-grammar entries, 46 percent, carry neither the temporal dimension
nor a catalytic mode. Either those entries are malformed or Axiom 4 is false, and
the implementation anticipates the second reading — it prints AXIOM FALSIFIED
rather than raising.
