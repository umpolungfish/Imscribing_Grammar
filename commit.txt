The provider capped every call at 4096 tokens and gave up after 60 seconds

An eight-phase ob3ect design does not fit in 4096 tokens, and the truncation
arrives as unparseable JSON, which the layer above reports as "the provider
returned no text". A working key looked like a dead lane for two runs on that
account. max_tokens=None now means uncapped: the field leaves the payload
entirely.

The non-streaming path also had a sixty-second deadline, shorter than a design
call, and a timeout there returns empty text rather than raising — the same
failure wearing the same disguise. Both paths now run without a deadline.
