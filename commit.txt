navigators: read a bare catalog name as `entry <name>`

The agent kept typing `cl9nk perfect_cuboid_proof` instead of
`cl9nk entry perfect_cuboid_proof`. The navigator called that an
unknown action, and the harness then advised imscribing the entry —
which already existed. So a dropped keyword read as a missing reagent
and sent the run off to mint one.

Now a bare first token that resolves to a catalog entry is read as
`entry <name>`, and the reading is announced rather than applied
silently. A token that is neither an action nor an entry still refuses.
