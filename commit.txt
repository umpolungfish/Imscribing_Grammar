A winding without a tool call says what is wrong, then ends the run.

The emission gate fired the same empty echo every time a model returned no tool call, which hands back nothing to act on, so a model that had stopped emitting kept not emitting and the run burned every remaining winding on that no-op. The forced command now states the problem and names the way out, and after three consecutive such windings the run closes itself through done rather than spinning to the ceiling. A real tool call clears the count.
