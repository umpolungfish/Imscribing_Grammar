Shout only about new slot-category violations

Thirty known violations printed thirty warning lines on every catalog write,
which buries the only line that matters: one that was not there before.

Known violations are now baselined in a sidecar and summarised in a single INFO
line. Anything absent from the baseline is reported in full at WARNING and folded
in, so each violation is shouted about exactly once and never again. Verified: a
clean write emits one summary line, and injecting a single new violation surfaces
it by name against the same thirty-strong baseline.

The thirty are unchanged and still need values from the emitter. This only stops
them drowning the next one.
