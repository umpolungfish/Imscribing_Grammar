There is one catalog

Six repositories each held a real copy, and a script existed to detect when they
drifted apart and to repair them by copying again. That script was enforcing the
copies: handed a link, it deleted the link and wrote a fresh copy in its place.

Every consumer is now a link to the catalog. Drift is not detected and repaired, it
is impossible, because there is one file and everything queries it.

The reason recorded for keeping copies was that a container build does a plain COPY
of the file and a link would break it. That is the build's concern: a context
assembled with links resolved carries the file itself, and the Dockerfile now says
so where the copy happens.

The check reports a consumer that is not the catalog, rather than a consumer whose
copy differs.
