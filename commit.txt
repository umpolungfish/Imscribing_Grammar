The roster promised a tool that did not exist, and a running agent could not see
a new one.

`imscribe(tool_name="list")` now names every grammar tool with its arguments and
the call form. The roster text had been telling agents to call it since the
roster was written, so an agent following its own instructions got
"Unknown tool: list" and then had to guess its way to anything. The roster line
also named the parameter `tool` where the dispatcher takes `tool_name`, and it
implied the base roster covered the grammar tools; it says now that the roster
is the base set and `list` is how to reach the rest.

The lattice_flow import reloads when an expected function is absent. A
long-running agent holds whatever copy of a module it imported first, so a
function added mid-session is missing from the cached copy and the call fails
with "has no attribute" against a file that plainly has it. Seen live:
imasm_transitions returned that error while the function was present on disk and
importable from a fresh process.

Neither is a failure of the agent. Both are the harness telling it something
untrue and then reporting its compliance as an error.
