momonados_operator: a specialist that reads the kernel instead of reciting it

The ⊙perator team gains its eighth member, for mOMonadOS itself: every command
the kernel exposes, present and future.

The prompt carries no command list, and that is the design rather than an
omission. The surface is 172 menu entries against 294 dispatch arms and it moves
whenever a command is added; a list written into a prompt is wrong the first
time that happens, and a confidently stale list is worse than a pause. So the
specialist discovers the surface every session from the three places that hold
it — src/menu.rs for what is documented, src/repl.rs for what actually
dispatches, and a boot for the last word — and it is told that where those
disagree, the disagreement IS the finding: an arm with no menu entry is an
undocumented command, a menu entry with no arm is a promise the kernel does not
keep.

The same reasoning governs the marker list in check_manifests.py. Those markers
are places to read — menu.rs, repl.rs, run_serial_cmds.sh, make image, make
ordinals, check_menu_coverage.py — never command names, because a command name
in a conformance check would enforce exactly the staleness this avoids.

What it does carry is the part that does not drift: batch commands because the
QEMU boot dominates and there is no timeout; rebuild with make image or you are
reading the previous binary; IMASM words are glyphs and never opcode names; the
six build targets and why a plain cargo build --features hosted fails in a way
that looks like rot and is not.

Wired the way the others are — TOOL_MANIFEST_momonados.md is generated by
gen_tool_manifest.py, which now carries a momonados domain, and the hand-written
chains live in WORKFLOWS_momonados.md so the generator cannot overwrite them.
check_manifests reports 6/6 domain markers. Aliases m⊙ and m⊙i in ~/.bashrc.

The other TOOLS_*.md files move because regenerating one regenerates all: they
pick up this morning's schema fix, so the crystal examples now read {'⊙': '⊙'}
and {'◻': '𐑭'} instead of Phi and Omega.

Not run end to end: OpenRouter is out of credits, so the live test reached the
API and stopped at 402. Everything up to the model call is verified.
