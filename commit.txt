UNIOPENPROB.md: fix truncated Shavian tuples in tables (2026-05-31)
==================================================================

  Root cause: pandoc allocates pipe-table column widths proportional to
  separator dash counts. Old Tuple separator (7 dashes) gave only 18% of
  page width; $d(ZFC_{fe})$ separator (16 dashes) wasted 42% on 1-2 digit
  numbers. Shavian strings need ~38% to render untruncated.

  Fixes:
  - Rebalanced separators: Tuple column 38 dashes, $d$ column 5 dashes
  - Wrapped all Shavian tuples in backticks (→ \texttt{} in LaTeX,
    prevents reflow mid-character and stabilizes display-width measurement)
  - Shortened column header $d(ZFC_{fe})$ → $d$ (avoids wide LaTeX math
    in header from inflating that column's minimum width)
  - Added italic footnotes below each table restoring the full header text
