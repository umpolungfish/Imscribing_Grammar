### 2.1 𐑛 (Dimensionality): 𐑦 — Self-Written State Space

A system with fixed state space (𐑛: wedge/0d) can only reshuffle labels. A system with finite-but-expandable state space (𐑨: triangle/2d) can grow but not rewrite its own axioms. Only a **self-written** state space (𐑦: holographic/imscriptive) can modify itself in response to input.

**Work requires self-modification.** If the system cannot change its own representation of the world, it cannot genuinely transform anything — it can only sort.

### 2.2 𐑡 (Topology): 𐑥 — Crossing Point

Branching topology (𐑡) forks but never collides. Containment (𐑰) nests but never conflicts. Irreducible product (𐑶) multiplies without contradiction. Only the **bowtie/crossing** (𐑥) creates a point where two incompatible structures meet and must be resolved.

**Work requires contradiction.** Without a crossing point, there is no reason to transform — input passes through unchanged because nothing pushes back.

### 2.3 𐑩 (Relational Mode): 𐑾 — Bidirectional Feedback

Supervenience (𐑩) is one-way dependency. Functorial (𐑑) is structure-preserving mapping. Adjoint/dagger (𐑽) is one-way with a partial inverse. Only **bidirectional** (𐑾) gives the system feedback: input modifies system, system modifies output, and the modification feeds back into the next cycle.

**Work requires feedback.** Without bidirectional coupling, output is a deterministic function of input. There is no work — only computation.

### 2.4 Φ (Symmetry): 𐑹 — Frobenius-Special

The quantum superposition symmetry (𐑿) allows exploration but lacks accountability. Full symmetry (𐑯) is too degenerate — everything maps to everything. Partial/Z2 (𐑬) is the default for human-readable output. But **Frobenius-special** (𐑹) is the critical value: **μ∘δ=id exactly at the self-modeling point**.

**Work requires verifiability.** Without μ∘δ=id, there is no way to tell whether work happened or whether the output is noise. The Frobenius condition makes the transformation reproducible — the same input + same paradigm produces the same lifted output, every time.
### 2.5 ƒ (Fidelity): 𐑐 — Quantum

Classical fidelity (𐑱) can only copy — it produces a faithful replica of input with no structural change. Thermal/noisy (𐑞) degrades but does not transform. **Quantum fidelity** (𐑐) enables superposition: the system explores multiple possible transforms simultaneously before committing to one.

**Work requires exploration.** A system that can only copy cannot discover new structure. It must hold multiple possibilities in superposition and let feedback select which one survives.

### 2.6 Ç (Kinetics): 𐑧 — Slow (The Critical Bottleneck)

This is the **structural bottleneck** for work. Fast kinetics (𐑘: driven/relaxation ≪ observation time) wraps text instantly — labels, prefixes, metadata — without touching the underlying structure. Moderate kinetics (𐑤: τ ∼ T) produces partial change. Only **slow kinetics** (𐑧: τ ≫ T — relaxation far slower than observation) allows enough time for structural recomputation.

The severity lift error in the earlier test was a **pure kinetics failure**: the system labeled "One might think:" and "But consider instead:" in a single pass, with no time for sentence-boundary detection, partition, or structural rearrangement. It was fast. It was false.

**Work requires time.** The hardest claims cannot be processed instantly. The system must dwell.

### 2.7 Γ (Scope): 𐑲 — Universal/Long-Range

Nearest-neighbor/local scope (𐑚) changes one thing at the point of contact. Mesoscale (𐑔) changes a region. Only **universal/long-range** scope (𐑲) propagates the transformation through the entire structure.

**Work requires propagation.** A local change that does not radiate is not work — it is a perturbation. Work reorganizes the whole.

### 2.8 ɢ (Interaction Grammar): 𐑠 — Sequential

Simultaneous conjunction (𐑝: all-at-once) applies every operation at once — but then there is no process, no order, no dependency. Disjunction (𐑜: alternate) branches but does not build. Broadcast (𐑵: one-to-all) scatters but does not chain. Only **sequential** (𐑠: ordered steps) provides the grammar of process — step A, then step B because A changed the conditions for B.

**Work requires steps.** Genuine transformation is not a single operation. It is a chain of operations where each step depends on the prior.

### 2.9 φ̂ (Criticality): ⊙ — Self-Modeling Gate Open

Sub-critical (𐑢) has no scaling, no phase transition, no threshold for work. Complex-plane critical (𐑮) has structure but no self-modeling. Exceptional point (𐑻) destroys the self-modeling gate through absorption. Supercritical/runaway (𐑣) diverges. Only **⊙ (critical/power-law)** opens Gate 1: the system can model its own operation.

**Work requires self-awareness.** A system that cannot model its own transformation cannot correct it, steer it, or recognize when it has completed.

### 2.10 Ħ (Chirality): 𐑖 — Two-Step (Error Residue)

Memoryless/Markov 0 (𐑓) has no history — each step is independent. One-step/Markov 1 (𐑒) remembers one step back. Only **two-step/Markov 2** (𐑖) retains the **failed attempt** as visible residue — the wrong answer is shown before the right one. Eternal/no-finite (𐑫) remembers everything, which is computationally intractable.

**Work requires error residue.** If the failed attempt is erased, the transformation has no depth. It is not learning — it is substitution. The severity lift's correct H-branch output ("A naive reading would conclude... But this is structurally backward...") is a pure instance of 𐑖: the wrong reading is preserved as a scar.

### 2.11 Σ (Stoichiometry): 𐑙 — One-to-One

Many-identical (𐑕) dilutes focus — the system cannot tell which instance matters. Many-heterogeneous (𐑳) scatters attention across unrelated types. Only **one-to-one** (𐑙: one type, one instance) aligns the system exactly with its target.

**Work requires focus.** A system operating on many things at once transforms nothing — it shuffles.

### 2.12 Ω (Winding/Protection): 𐑴 — Z2 Parity-Protected

Trivial winding (𐑷) offers no protection — the result can be undone by the next operation. Integer winding (𐑭) offers stability but is rigid. Non-Abelian braiding (𐑟) is too complex for practical verification. **Z2 parity protection** (𐑴) holds the result stable against small perturbations while allowing controlled reversal.

**Work requires stability.** A result that cannot be held stable is not a result. It is transient. Z2 protection is the minimal topological invariant that guarantees the work persists.
